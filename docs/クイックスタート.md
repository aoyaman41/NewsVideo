# クイックスタート

このドキュメントは、初めて使う人が最短で 1 本目の動画を作るための手順です(2026-09-26 の画面に合わせています)。

## 1. 先に結論

- 既定の構成では、**Anthropic・OpenAI・Google の 3 つの API キー**が必要です
  - 文章(台本と画像の指示): `Claude Opus 5.5`(Anthropic)
  - 画像: `GPT Image 2.5 Sunburst`(OpenAI)
  - 音声: `Gemini 3.8 Flash TTS`(Google)
- 初回起動時の「ようこそ」画面で、3 つのキーを 1 画面で設定できます
- API キーがなくても、完成したサンプルを開いて操作を試せます
- 記事を貼り付けて「おまかせで作る」を押すと、台本 → 画像 → 音声 → 動画まで自動で進みます
- API の利用料は NewsVideo ではなく、各サービスの契約に対して直接かかります

## 2. インストール

### 配布版

1. [GitHub Releases](https://github.com/aoyaman41/NewsVideo/releases/latest) から最新版を取得します
2. `.dmg` を開いて `NewsVideo.app` を `Applications` にコピーします
3. アプリを起動します

補足:

- 現在の Public Beta 配布物は `Developer ID` 署名 / `notarization` なしです
- これは未着手ではなく、個人開発 OSS の現状では年額コストと運用負荷に見合わないため、意図的に見送っているものです
- 初回起動時に macOS の Gatekeeper 警告が出る場合があります
- 警告の意味と回避手順は [macOSインストールとGatekeeper](./macOSインストールとGatekeeper.md) を確認してください

### 開発版

```bash
npm install
npm run dev
```

必要環境は `macOS` と `Node.js ^20.19.0 || >=22.12.0` です。

## 3. 最初の設定(ようこそ画面)

初回起動時(プロジェクトがまだないとき)、必要な API キーがそろっていなければ「ようこそ」画面が開きます。

1. 各サービスの「〜の管理画面でキーを作る」を押し、ブラウザでサインインして API キーを作成・コピーします
   - Anthropic(Claude): 台本と画像の指示を作るのに使います
   - OpenAI: 画像を作るのに使います
   - Google(Gemini): ナレーションの音声を作るのに使います
2. コピーしたキーを入力欄に貼り付けて「保存して確認」を押します
3. 状態が「使えます」になれば完了です。「使えません」のときは、表示された案内に従ってキーを貼り直します
4. 3 つとも設定できたら「はじめる」を押します

補足:

- あとで設定する場合は「あとで設定する」を押します。`設定 > API キー` からいつでも設定でき、同じ画面の「はじめの案内を開く」で、ようこそ画面を開き直せます
- 「サンプルを見る」を押すと、API キーなしで完成サンプルを開けます
- キーはこの Mac の中に暗号化して保存し、そのサービスへの接続にだけ使います
- 「保存して確認」は、キーでサービスに接続できるかを確かめるものです。選んだモデルの利用権限や利用枠までは保証しません

### 使うサービスを変えたいとき

`設定 > 生成モデル` で、用途ごと(文章 / 画像 / 音声)に使うモデルを選べます。必要な API キーはモデルに合わせて変わり、キーが未設定のときはその場で案内が出ます。

- Google のキー 1 つで始めたい場合: 文章を `Gemini 3.1 Pro`、画像を `Gemini 3.1 Flash Image` にします(音声は既定で Google を使います)
- 台本と画像の指示で別のモデルを使いたい場合や、「思考の深さ」(既定は「中」)を変えたい場合は `設定 > 詳細設定` で変えられます

## 4. 1 本目の動画を作る

1. `プロジェクト` 画面で「新しい動画を作る」を押します(プロジェクトがまだないときは最初から表示されています)
2. 動画の種類(90 秒・定期ニュース / 3 分・じっくり解説 / 60 秒・縦型ダイジェスト)を選び、「作成して記事を入力する」を押します
3. `記事` 画面で、タイトルと本文を貼り付けます。すぐ試したい場合は [サンプル記事](./サンプル記事.md) を使います
4. ボタンの上に出る「費用の見込み」(「約 X 円($Y)」と、多くてこのくらい)を確認して、「おまかせで作る」を押します
5. 画面上部に進み具合が表示されます。ほかの画面に移っても止まりません。止めたいときは上部の「停止」を押します
6. 完成すると通知が出ます。上部の「動画を見る」を押して動画画面を開きます
7. 動画画面で、左の一覧からシーンを選んで「シーン N をプレビュー」で確認します。「字幕を入れる」の ON/OFF と「締めの画面」(見出し・ひとこと)は、必要なら変えます
8. 「動画を書き出す」を押すと、動画ファイルに書き出します。書き出し中は進み具合が表示され、「止める」で止められます

補足:

- 入力は自動で保存されます(保存ボタンはありません)。保存の状態は画面右上に表示されます
- シーン数・1 シーンの長さ・締めのひとこと・画像の雰囲気・画面の縦横・読み上げの話し方・進め方・予算は、記事画面の「詳細設定」でその動画だけ変えられます。これから作る動画の既定値は `設定 > 新しい動画` で変えます
- 途中で止まった場合は、記事画面または画面上部の「続きから」で、止まったところから再開できます。台本から作り直したいときは「最初から作り直す」を押します
- 台本ができたあとにシーン数を変えて「おまかせで作る」を押すと、台本から作り直すかを確認します
- 各シーンを直したいときは、台本・画像・音声の各画面で作り直せます
  - 台本: 文章を直接直すか、「AI に書き直してもらう」で直したい点を書いて「書き直す」
  - 画像: 「画像を作る」「N 枚目を作り直す」。思いどおりでないときは「指示を足して作り直す」で、足したい内容を書いてから作り直します。画像がないシーンは「足りない画像を作る」でまとめて作れます
  - 音声: 音声がないシーンは「足りない音声を作る」でまとめて作れます。読み間違いは `設定 > 読み辞書` で直してから作り直します
- 「確認しながら」進めたい場合は、「詳細設定」の「自動生成の進め方」で「台本と素材ができたところで止めて確認する」を選びます。止まったときは画面上部の「確認して続ける」で再開します

## 5. よくあるつまずき

エラーが起きると、原因と次にやること(「API キーを設定する」「別のモデルを選ぶ」「もう一度試す」など)がボタン付きで表示されます。元のエラー文は「詳しい内容」を開くと見られます。

### 「〜の API キーが設定されていません」と出る

- 原因: 今の設定で使うサービスの API キーが保存されていません
- 対処: 「API キーを設定する」を押してキーを保存し、「続きから」で再開します

### 「〜の API キーが使えません」と出る

- 原因: キーの貼り付けミス、キーの無効化、サービス側の支払い設定や利用権限の不足
- 対処: キーを貼り直して「保存して確認」を押します。サービス側の設定も確認してください

### 「AI がこの記事の生成を断りました」と出る

- 原因: AI の安全上の判定で生成が止まりました(感染症などの報道で起きることがあります)。別のモデルへの自動切り替えは行いません
- 対処: 「別のモデルを選ぶ」から文章のモデルを別のもの(例: `GPT-5.6 Terra`)に変え、記事画面の「最初から作り直す」で再実行します

### 「予算の上限に近づいたため、自動生成を止めました」と出る

- 原因: 記事画面の「詳細設定」にある「1 回の予算の上限」に近づきました
- 対処: 画面上部の「上限を外して続ける」を押すか、予算を増やしてから「続きから」を押します

### 「AI サービスの利用上限に達しました」と出る

- 原因: サービス側の利用枠(レート制限・クォータ)に達しました
- 対処: 少し待ってから「続きから」を押します。続く場合はサービス側の利用枠や支払い設定を確認します

### 「動画の書き出しが進まなくなったため中断しました」と出る

- 原因: 書き出しが 90 秒以上進まなかったため、自動で止めました。Mac の負荷が高いときに起きることがあります
- 対処: ほかのアプリを閉じるか、「動画の設定を開く」から動画の大きさを小さくして、もう一度書き出します(自動生成なら「続きから」)

### 「書き出しを待つ間に動画の内容が変わりました」と出る

- 原因: 書き出しやプレビューの順番を待つ間に、シーン・画像・音声・字幕・締めの画面のどれかが変更されました
- 対処: 今の内容を確認してから、もう一度「動画を書き出す」(プレビューなら「シーン N をプレビュー」)を押します
