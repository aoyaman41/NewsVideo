# 制作ワークスペース

## はじめて使うとき

初回起動時(プロジェクトがまだないとき)、今の設定で必要な API キーがそろっていなければ「ようこそ」画面が開きます。Anthropic・OpenAI・Google の 3 つのキーを、取得先のリンク → 貼り付け → 「保存して確認」の順に 1 画面で設定できます。「あとで設定する」で閉じると、次回からは自動では開きません(`設定 > API キー` の「はじめの案内を開く」で開き直せます)。「サンプルを見る」は API キーなしで完成サンプルを開きます。

## 新しい動画を作る

プロジェクト画面の「新しい動画を作る」で、動画の種類(90 秒・定期ニュース / 3 分・じっくり解説 / 60 秒・縦型ダイジェスト)を選びます。名前は入力せず、最初の記事タイトルが名前になります。「サンプルを開く」は macOS の音声とアプリで作る図形を使い、API キーなしで完成動画と編集用データを作ります。

記事画面では、タイトルと本文を貼り付けて「おまかせで作る」を押します。用途・シーン数・1 シーンの長さ・締めのひとこと・画像の雰囲気・画面の縦横・読み上げの話し方・自動生成の進め方・予算は「詳細設定」にまとめています。記事に関係する写真は「写真を追加(任意)」から登録でき、画像画面でシーンの画像として使えます。テキストファイルの読み込みは廃止しました(本文は貼り付けで入力します)。

## 保存と再開

記事・台本の入力は共有ストアへ即時反映し、約 400ms 後に Main へ保存します。画面移動でも保存処理を続行します。ウィンドウを閉じる前には保存完了を待ちます。保存の状態は画面右上の 1 か所にだけ表示し、失敗したときは「保存できませんでした」と「もう一度保存」を出します。別の保存との競合は変更箇所を照合し、重なる編集は「この画面の内容で保存」か「保存済みの内容に戻す」を選びます。

v2 のプロジェクトは `project.json` が記事・素材参照・台本・ジョブをまとめた保存単位です。書き換え前の完全な状態を `project.previous.json` に保持します。旧形式は読み込み、次の保存で移行します。壊れた保存と未対応バージョンを空のプロジェクトとして扱いません。画面から外した機能の保存データ(出典の記録・根拠・素材の権利・字幕の細かい編集など)は、スキーマから消さずにそのまま保持します。

## 自動生成と費用

「おまかせで作る」は、台本 → 画像 → 音声 → 動画をまとめて進めます。既定は最後まで自動で進め、確認のために止めません。「詳細設定」の「自動生成の進め方」で「台本と素材ができたところで止めて確認する」を選ぶと 2 か所で止まり、画面上部の「確認して続ける」で再開します。

自動生成の進み具合は、どの画面にいても画面上部に表示します。工程ごとの進み具合(台本・画像・音声・動画)と全体のバーを出し、ジョブが工程ごとの進み具合を記録していない場合は、今の段階の名前で代替します。上部の「停止」で止め、「続きから」で止まったところから再開します。完成すると通知と「動画を見る」ボタンを出します。自動生成の実行中は、動画画面の書き出しとプレビューを使えません。記事画面から開始する自動生成ジョブは Main で動作し、各段階の結果を保存します。画面移動では停止しません。アプリの再起動後は明示的な再開まで追加課金しません。

「続きから」は、止まったジョブを開始したときの設定(モデルなど)で再開します。記事画面の「詳細設定」の進め方と予算は、止まっているジョブがあるときはそのジョブの値を初期値として表示し、「続きから」ではその値を使います。新しい設定で作り直すときは、記事画面の「最初から作り直す」を使います(台本から作り直します。台本があるときに表示します)。台本ができたあとにシーン数を変えて「おまかせで作る」を押すと、台本から作り直すかを確認します。

エラーで止まったときは、例外の文字列をそのまま出さず、原因と次の操作をボタン付きで示します(API キーの未設定・認証の失敗 →「API キーを設定する」、AI の拒否 →「別のモデルを選ぶ」、利用上限・接続の失敗 →「続きから」)。元のエラー文は「詳しい内容」を開くと見られます。

停止要求と API 応答が重なった場合、その応答を保存してから次の段階を止めます。応答時に入力が変わっていた場合も結果をジョブに保全します。過去のジョブの結果はプロジェクトに記録として残します(画面から取り出す機能とジョブ ID の表示は廃止しました)。

費用は、記事画面で「おまかせで作る」の前に「費用の目安」を、完成時に「今回の費用の目安」を表示します。累計の費用の常時表示はやめました。予算は次の要求の推定費用に余裕を加えて確認するため、API の請求額を厳密に制限する機能ではありません。予算の上限に近づいて止まったときは、画面上部の「上限を外して続ける」、または予算を増やしてから「続きから」で再開します。料金未確定の記録があるだけでは予算で止まりません。

## 台本・画像・音声・動画の各画面

各シーンを直したいときは、台本・画像・音声の各画面で作り直します。画面上部の工程ナビ(記事 → 台本 → 画像 → 音声 → 動画)で各画面へ移動でき、各工程の状態(できている / 途中 / まだ)が分かります。

記事、台本、画像の指示、声、見た目が変わると、対応する生成物は更新対象になります。古い入力で作った動画を現在の完成状態と混同しません。

字幕は動画画面で表示の ON/OFF を切り替えます。読み間違いは、設定の「読み辞書」で直します。

## 読み辞書

`設定 > 読み辞書` で、ナレーションで読み間違える言葉の表記と読みを登録します(全プロジェクト共通、最大 500 件)。表記と読みの両方がある行だけを保存し、同じ表記が複数あるときは上の行を使います。登録した読みは、このあと作る音声から使われます。作成済みの音声は音声画面で作り直すと反映されます。

## 設定

設定画面は「API キー」「生成モデル」「動画」「読み辞書」「詳細設定」に分かれています。変更は自動で保存されます。

- 生成モデル: 用途ごと(文章 = 台本と画像の指示 / 画像 / 音声)にモデルを選びます。使う API キーが未設定のときは、その場で案内を出します
- 動画: 動画の大きさ、新しいプロジェクトの画面の縦横、最初・最後に流す動画
- 詳細設定: 自動生成の進め方と予算、台本と画像の指示のモデルを別々に選ぶ設定、思考の深さ(推論の強さ)、同時に処理する数、フレームレート・ビットレート・シーンの読み上げ前の間、診断ファイルの保存

生成モデル・声・読み辞書の既定値を変えると、実行中でないプロジェクトの関連素材を更新対象にします。実行中または再開する自動生成は開始時の設定を使います。動画の前後素材・読み上げ前の間・品質は書き出し時の設定をプロジェクトに保存し、字幕書き出しでも同じ値を使います。

## 管理・共有・診断

プロジェクトごとの「…」メニューから、複製、テンプレートとして複製(記事なし・見た目と設定だけ)、アーカイブ、素材込みバックアップの保存、ごみ箱へ移動を行います。一覧の右上の「…」メニューから、アーカイブしたものの表示、バックアップから復元、ごみ箱を開く(元に戻す)、サンプルを開くを行います。`.newsbackup` フォルダー全体を別の Mac へ渡し、バックアップから復元してください。素材を相対パスで格納し、新しいプロジェクト ID で復元します。絶対パス・範囲外参照・symlink 逸脱は拒否します。

バックアップには記事と画像・音声などの内容が含まれます。API キーは含まれません。生成中は停止してからバックアップします。

`設定 > 詳細設定 > サポート` の「診断ファイルを保存」は、状態・件数・版・OS だけを JSON へ書き出します。記事本文、名前、ファイルパス、API キーは含めません。外部送信はしません。共有前に内容を確認してください。

制作記録(初回出力までの経過時間、台本編集率、生成要求数、再開・停止など)は、この Mac のプロジェクトにだけ記録を続けます。プロジェクト一覧の制作記録の表は廃止しました。
