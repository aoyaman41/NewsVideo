# 制作観察と比較

## 記録項目

各制作で、用途、記事の文字数、シーン数、比率、使用モデル、初回プレビュー時刻、初回出力時刻、修正したシーン数、生成要求数、失敗分類、停止・再開回数、推定料金と未確定料金を記録します。本文と個人情報を比較表へ転記しません。

時間はアプリで作成時刻からの経過時間を記録します。離席を含むため、人の操作時間を比較する場合は観察者が別に記録します。修正率は現在の `scriptModifiedByUser` が付いたシーンの割合です。編集内容の正しさや作業量そのものではありません。

## 5本の制作

最初の検証では横型2本、縦型2本、正方形1本を作り、同じ固定素材で保存、素材配置、字幕、プレビュー、書き出しを通します。API不要サンプルによる検証記録と、外部記事・有料APIを用いた実制作は区別します。

1. 90秒ニュースの用途を選び、原稿を入力してすぐ工程を切り替える。
2. 60秒縦型を選び、シーンを分割し画像を差し替える。
3. 3分解説の用途を選び、字幕の時刻と読みを修正する。
4. 縦型で編集可能な見出し・棒グラフを重ね、文字の切れを確認する。
5. 正方形でバックアップを別の保存場所から復元し、再編集・書き出しする。

各回で停止・再開、保存エラーまたは生成エラー時の復旧を少なくとも一つ含めます。実際に実行していない操作は空欄にし、成功と記録しません。合成障害のテスト結果を利用者の観察結果として数えません。

## 比較方法

旧版の制作時間・料金の基準データは収集されていません。旧版を0秒・0円として改善率を作りません。今後、同一記事・同一素材・同一モデル・同一Macで5本ずつ測定し、中央値と範囲、失敗回数、修正率を併記します。モデル/APIの変化や待機時間が異なる場合は別群にします。

キーボードのみ、VoiceOver、拡大表示は別の観察項目とし、レイアウトのスクリーンショットだけで適合を宣言しません。
