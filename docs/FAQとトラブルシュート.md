# FAQとトラブルシュート

このドキュメントは、NewsVideo の `Public Beta` を初めて使うときに詰まりやすい項目を、自己解決しやすい順に整理したものです。

## アプリが起動しない

### 症状

- 初回起動で macOS の警告が出る
- `Apple could not verify ...` や `developer cannot be verified` と表示される

### まず確認すること

- 配布版は `macOS / Apple Silicon (arm64)` 向けです
- 現在の Public Beta 配布物は `Developer ID` 署名 / `notarization` なしです
- これは未着手ではなく、個人開発 OSS の配布規模では年額コストと運用負荷に見合わないため、現時点で意図的に見送っています

### 対処

- まず [macOSインストールとGatekeeper](./macOSインストールとGatekeeper.md) の手順を確認してください
- `Applications` にコピーしたうえで、`control`-click または右クリックから `開く` を試してください
- 管理対象 Mac や厳しいセキュリティポリシーの端末では実行できない場合があります

## なぜ `Developer ID` 署名 / `notarization` をしていないのか

- 個人開発の `OSS Public Beta` として公開しており、現時点では Apple Developer Program の年額コストと運用負荷に見合わないと判断しています
- その代わり、未署名 / 未 notarize であることと Gatekeeper 回避手順を先に明示しています
- 署名済み配布が必須の環境では、この Public Beta は現時点では向きません

## API キーの「保存して確認」が「使えません」になる

### まず確認すること

- キーの貼り付けミスがないか(前後の空白や、途中で切れていないか)
- 対象サービス側で API 利用が有効になっているか(支払い設定・利用権限)
- ネットワークや VPN、社内プロキシが接続を止めていないか

### 対処

- 「使えません」の下に表示される案内に従います。元のエラー文は「詳しい内容」で確認できます
- キーを作り直して貼り付け、もう一度「保存して確認」を押します
- 今の設定でどのキーが必要かは、`設定 > API キー` の各行(「〜を作るのに使います」)と、`設定 > 生成モデル` の各項目で確認できます

## 自動生成が途中で止まった

画面上部に止まった理由と、次の操作のボタンが表示されます。

| 表示 | 原因 | 対処 |
| --- | --- | --- |
| 「〜の API キーが設定されていません」 | 今の設定で使うサービスのキーがない | 「API キーを設定する」でキーを保存し、「続きから」 |
| 「〜の API キーが使えません」 | キーの誤り・無効化・支払い設定の不足 | キーを貼り直して「保存して確認」、そのあと「続きから」 |
| 「AI がこの記事の生成を断りました」 | AI の安全上の判定(感染症などの報道で起きることがある) | 「別のモデルを選ぶ」で文章のモデルを変え、記事画面の「最初から作り直す」 |
| 「AI が安全上の理由で生成を断りました」 | 画像などを作るときの安全上の判定 | 記事や指示の内容を見直すか、「別のモデルを選ぶ」でモデルを変えてから「続きから」 |
| 「AI サービスの利用上限に達しました」 | サービス側のレート制限・利用枠 | 少し待ってから「続きから」。続く場合はサービス側の利用枠を確認 |
| 「AI サービスに接続できませんでした」「AI サービスが混み合っています」「AI サービスから応答がありませんでした」 | ネットワークやサービス側の一時的な障害 | 接続を確認し、少し待ってから「続きから」 |
| 「動画の書き出しが進まなくなったため中断しました」 | 書き出しが 90 秒以上進まなかった(Mac の負荷が高いときなど) | ほかのアプリを閉じるか、「動画の設定を開く」で動画の大きさを小さくしてから「続きから」 |
| 「書き出しを待つ間に動画の内容が変わりました」 | 書き出しの順番を待つ間に、シーン・画像・音声・字幕・締めの画面が変更された | 内容を確認してから、もう一度書き出す(自動生成なら「続きから」) |
| 「予算の上限に近づいたため、自動生成を止めました」 | 記事画面の「詳細設定」の予算の上限 | 「上限を外して続ける」、または予算を増やしてから「続きから」 |
| 「アプリが終了したため、自動生成が途中で止まっています」 | 生成中にアプリを終了した | 「続きから」(作ったものは保存されています) |

補足:

- 「続きから」は、止まったジョブを開始したときの設定で再開します。生成モデルを変えたあとに新しい設定で作るときは、記事画面の「最初から作り直す」を押します
- 作ったものは停止しても保存されます
- 失敗が続く場合は、「詳しい内容」の文と操作手順を控えて Issue を作成してください

## 課金は誰負担か

- API 利用料は NewsVideo ではなく、ユーザー自身の OpenAI / Google AI / Anthropic 契約に対して直接発生します
- ローカルアプリの利用それ自体ではなく、生成時の API 呼び出しに対して課金されます
- 詳細は各プロバイダの料金体系を確認してください

## 対応環境と非対応環境はどこまでか

### 公式に案内している範囲

- `macOS / Apple Silicon (arm64)` の配布版
- `macOS` 上でのソースビルド

### 現在サポートしないもの

- `Windows`
- `Linux`
- `Intel Mac`
- 商用 SaaS のような継続サポートや SLA

詳細は [対応環境と制約](./対応環境と制約.md) を確認してください。

## それでも解決しない場合

- まず `README`、[クイックスタート](./クイックスタート.md)、[対応環境と制約](./対応環境と制約.md) を見直してください
- そのうえで再現条件がある場合は、[Issue 作成画面](https://github.com/aoyaman41/NewsVideo/issues/new/choose) から報告してください
- 個人開発の `OSS Public Beta` のため、サポートは `best effort` です
